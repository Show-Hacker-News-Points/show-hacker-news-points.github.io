Y Show Hacker News Points

Every Hacker News story with 400 or more points, published as files for the Reveal Top Hacker News Stories extension. The extension checks the pages you visit against this list on your own machine, so it never has to ask a server about them.

The list is rebuilt from the Algolia HN API every six hours.

  • v2/index.json: for extension 1.2 and later. It names the archive file that holds the older stories.
  • feed.pb: for extension 1.1 and older.

Not affiliated with Hacker News or Y Combinator.
